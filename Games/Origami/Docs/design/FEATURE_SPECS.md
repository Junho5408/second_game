## 공통 표기 (수용 기준용)

- 명령은 `GAME_RULES.md` "명령" 표를 따른다. "거부(사유)" = 명령이 거부되고 상태가 전혀 바뀌지 않음(R-019).
- 줄임말:
  - `Sit` = `Interact(table)`, `Stand` = `StandUp`.
  - `Ref(m)` = (앉은 상태에서) `TakeSheet` → `CONTENT_SPECS.md` §2의 m 순서를 그대로 `Fold` → `Finish`. m을 보유했으면 m ★3(100%).
  - `Var(dy)` = `TakeSheet` → `Fold((−1,1),(−1,−1))` → `Fold((−1,0),(−0.6,−0.8+dy))` → `Fold((1,0),(0.6,−0.8+dy))` → `Finish`.
    `Var(0.03)` = house ★3(97%), `Var(0.1)` = house ★2(92%), `Var(0.2)` = house ★1(86%) (`CONTENT_SPECS.md` §4 J-04~J-06).
  - `Waste` = `TakeSheet` → `Discard`.
  - `Night` = (앉아 있으면 `Stand`) → `Interact(bed)` → `Sleep(yes)`.
- 따로 말하지 않으면 시나리오는 `NewRun` 직후(1일차, 돈 20, 걷기)에서 시작한다.
- **[Core]** 수용 기준은 Unity 없이 명령 열로 검증(dotnet). **[Unity]** 는 PlayMode 테스트 또는 사용자 플레이테스트로 검증한다.
- 좌표 비교 허용 오차: 종이 좌표 1e-6, 넓이 1e-6, 일치도 ±0.01, 월드 위치 ±0.05m(이동 ±0.15m).

### F-001 런 진행 (시작 · 하루 · 파산 · 종료)
- 목적: 7일 한 판의 뼈대.
- 관련 규칙: R-001, R-002, R-005, R-016, R-017, R-019, R-020
- 기대 동작: `NewRun` → R-002 상태. `Night` → 정산 후 다음 날(종이 5장) + 파산 검사, 7일차면 완주 종료. 종료 시 엔딩 판정(F-012). 종료 후 `NewRun` 외 모든 명령 거부(RunEnded).
- 엣지 케이스: 종이를 쓰지 않고 잠자기, 테이블에 종이를 둔 채 잠자기 시도, 낮 동안 돈 0, 아침 돈 정확히 2, 7일차 뒤 파산 검사 없음, 런 도중 `NewRun`.
- 수용 기준:
  - AC-01 [Core]: `NewRun` 직후 일차 1, 돈 20, 남은 종이 5, 보유 {plane, house}, 첫 종이 무료 남음, 모드 걷기, 테이블 종이 없음, 책 닫힘, 진열 0개, 모든 완성 수 0, 실패 0, 총 판매·종이값·책값 0, 종료 아님.
  - AC-02 [Core]: `Night` 1회 → 일차 2, 돈 20, 남은 종이 5, 모드 걷기, 첫 종이 무료 남음, 종료 아님.
  - AC-03 [Core]: `Night` 7회 → 종료(완주), 일차 7, 돈 20, 엔딩 E-01. 이어서 `Interact(table)`, `TakeSheet`, `Interact(bed)`는 각각 거부(RunEnded).
  - AC-04 [Core]: `Sit`, `TakeSheet`, `Stand`, `Interact(bed)` → 거부(SheetOnTable), 모드 걷기, 일차 1.
  - AC-05 [Core] (파산): `Sit`, `Waste`×5 → 돈 12, 남은 종이 0, `TakeSheet` 거부(NoSheetsLeft) → `Night` → 2일차 돈 12 → `Sit`, `Waste`×5 → 돈 2 → `Night` → 3일차, 종료 아님(돈 = 2) → `Sit`, `Waste` → 돈 0 → `TakeSheet` 거부(NotEnoughMoney), 남은 종이 4 → `Night` → 종료(파산), 일차 4, 돈 0, 실패 11, 엔딩 E-01.
  - AC-06 [Core] (낮 동안 돈 0은 파산 아님): AC-05의 3일차 `Sit` 다음에 `Waste` 대신 `Ref(house)` → 돈 0, 종료 아님 → `Night` → 3일차 house ★3 일반 12 → 4일차, 돈 12, 종료 아님.
  - AC-07 [Core]: 2일차에 `Sit`, `TakeSheet`, `Fold((−1,1),(−1,−1))` 후 `NewRun` → AC-01과 같은 상태.
  - AC-08 [Core] (결정성): 같은 명령 열(예: F-011 AC-01~AC-02 전체)을 새 런 두 개에 적용하면 일차, 돈, 남은 종이, 보유 페이지, 완성 수, 실패 수, 진열, 종료 여부, 엔딩이 모두 같다.
  - AC-09 [Core]: 위 모든 시나리오의 모든 시점에서 돈 = 20 + 총 판매액 − 총 종이값 − 총 책값, 돈 ≥ 0.
- 범위 밖: 저장/불러오기, 일수 변경.

### F-002 캐릭터 이동과 카메라
- 목적: 공방 안을 캐릭터로 직접 걸어 다니는 감각.
- 관련 규칙: R-003, `CONTENT_SPECS.md` §6
- 기대 동작: 걷기 모드에서 W/A/S/D 또는 방향키로 화면 기준 위/왼/아래/오른쪽(= 북/서/남/동) 이동, 속도 3.0 m/s, 대각선도 같은 속도. 캐릭터는 이동 방향을 바라본다. 벽·가구에 막힌다. 카메라는 고정 각도로 따라간다(회전 없음). 점프·달리기 없음.
- 엣지 케이스: 반대 키 동시 입력(W+S) → 그 축 정지. 걷기 외 모드에서는 이동 키 무시. 창이 포커스를 잃으면 이동 정지.
- 수용 기준:
  - AC-01 [Unity]: 새 런 시작 시 캐릭터 위치 (−2.0, 1.2) ±0.05, 동쪽을 바라본다.
  - AC-02 [Unity]: 시작 위치에서 D를 1.0초 누르면 x가 3.0 ±0.15 증가하고 z는 ±0.05 안에서 유지된다.
  - AC-03 [Unity]: W+D를 0.5초 누르면 이동 거리가 1.5 ±0.1m(대각선 정규화)다.
  - AC-04 [Unity]: A를 5초 누르면 x ≥ −3.75(벽 −4 + 반지름 0.3 − 0.05)이고 방 밖으로 나가지 않는다. 테이블·침대·책장·판매대를 뚫고 지나가지 않는다.
  - AC-05 [Unity]: 앉음·책장 읽기·판매대 보기·잠자기 확인 모드에서 이동 키를 1초 눌러도 캐릭터 위치가 ±0.01 안에서 변하지 않는다.
  - AC-06 [Unity]: 걷기 중 카메라는 캐릭터 기준 (0, 6.0, −5.5) 위치(따라가기 지연 후 ±0.2)에서 캐릭터를 바라보며, 마우스 입력으로 회전하지 않는다.
- 범위 밖: 1인칭, 카메라 회전, 점프·달리기, 문 열기, 방 밖.

### F-003 상호작용과 모드 전환
- 목적: 테이블·책장·판매대·침대를 사용해 하루를 보낸다.
- 관련 규칙: R-003, R-004, R-005, R-019
- 기대 동작: 상호작용 범위(1.2m) 안의 가장 가까운 대상에 "E: …" 안내가 뜨고, E로 사용. 모드별 키:
  - 걷기: 이동, E 상호작용, Esc 일시정지 메뉴(계속 / 새로 시작 — 새로 시작은 확인 후 `NewRun`).
  - 앉음: 마우스 왼쪽 끌기 접기, Shift 산접기, 오른쪽 끌기 시점 회전, 휠 확대, Space 종이 꺼내기, Enter 완성, X 버리기, Z/Backspace 되돌리기, R 다시 펴기, F 뒤집기, B 책 펴기/닫기, G 가이드 끄기, Q 일어나기, Esc 끌던 접기 취소. 같은 기능의 화면 버튼도 있다.
  - 책(책장 읽기 또는 앉음+책 펼침): ←/→ 쪽 넘기기(앉음에서는 책이 펴져 있을 때만), 목차 항목 클릭, "사기" 버튼. 책장 읽기에서는 Esc/E/B로 닫기.
  - 판매대 보기: Esc/E 닫기. 잠자기 확인: Enter = 예, Esc = 아니오. 정산 화면: Enter/버튼으로 다음 날.
- 엣지 케이스: 두 대상이 범위 안 → 가까운 쪽, 같은 거리 → table > bookshelf > counter > bed. 앉을 때 캐릭터는 의자 위치로 옮겨지고, 일어나면 의자 상호작용 지점 (2.5, 0.8)에서 남쪽으로 0.6m 떨어진 (2.5, 0.2)에 선다.
- 수용 기준:
  - AC-01 [Core]: `Interact(table)` → 앉음(책 닫힘). `Stand` → 걷기. `Interact(bookshelf)` → 책장 읽기, `CloseBook` → 걷기. `Interact(counter)` → 판매대 보기, `CloseCounter` → 걷기. `Interact(bed)` → 잠자기 확인, `Sleep(no)` → 걷기(일차 1 유지).
  - AC-02 [Core]: 앉음에서 `Interact(bookshelf)` → 거부(WrongMode). 걷기에서 `TakeSheet`, `Fold`, `StandUp`, `OpenBook` → 각각 거부(WrongMode). 책장 읽기에서 `Interact(bed)` → 거부(WrongMode).
  - AC-03 [Core]: `Interact(null)`과 정의되지 않은 대상 값 → 거부(UnknownTarget). 앉음에서 `Interact(null)` → 거부(WrongMode)(WrongMode가 먼저).
  - AC-04 [Core]: 앉음에서 `OpenBook` 두 번 → 책 펼침 유지(두 번째도 허용, 변화 없음). `Stand` → 걷기, 다시 `Sit` → 책 닫힘.
  - AC-05 [Unity]: 캐릭터가 의자 상호작용 지점에서 1.1m 떨어져 있으면 "E: 앉기" 안내가 보이고 E로 앉음 모드가 된다. 1.3m면 안내가 없고 E를 눌러도 모드가 바뀌지 않는다.
  - AC-06 [Unity]: 앉음 진입 후 0.5초(+0.1) 안에 카메라가 접기 시점에 도착하고 종이(있다면)가 화면 가운데 보인다. Q로 일어나면 걷기 카메라로 돌아가고 캐릭터는 (2.5, 0.2) ±0.05에 선다.
  - AC-07 [Unity]: 잠자기 확인에서 Enter → 정산 화면, 정산 화면에서 Enter → 캐릭터가 (−2.0, 1.2)에서 새 날 시작.
- 범위 밖: 물건 들고 다니기, 문, 손님.

### F-004 종이 꺼내기
- 목적: 종이값과 하루 5장이 선택을 제약한다.
- 관련 규칙: R-006, R-008
- 기대 동작: 앉음에서 `TakeSheet` → 테이블에 평평한 정사각형(조각 1개, 흰 면 위, 접은 횟수 0). 런의 첫 종이는 무료(튜토리얼), 그 밖은 돈 −2. 남은 종이 −1.
- 엣지 케이스: 이미 종이가 있음, 남은 종이 0, 돈 부족(돈 = 2는 허용), 첫 종이를 2일차에 꺼냄.
- 수용 기준:
  - AC-01 [Core]: `Sit`, `TakeSheet` → 돈 20, 남은 종이 4, 테이블 종이 있음(조각 1, 접은 횟수 0, 윤곽 넓이 4.0), 튜토리얼 종이, 가이드 보임.
  - AC-02 [Core]: 이어서 `Discard`, `TakeSheet` → 돈 18, 남은 종이 3, 총 종이값 2, 튜토리얼 종이 아님, 가이드 안 보임.
  - AC-03 [Core]: 종이가 있을 때 `TakeSheet` → 거부(SheetOnTable).
  - AC-04 [Core]: `Sit`, `Waste`×5 후 `TakeSheet` → 거부(NoSheetsLeft), 돈 12.
  - AC-05 [Core]: `Night`, `Sit`, `TakeSheet`(2일차 첫 종이) → 돈 20, 남은 종이 4, 튜토리얼 종이.
  - AC-06 [Core]: F-001 AC-05의 3일차 `TakeSheet` 거부(NotEnoughMoney) 확인(돈 0, 남은 종이 4). 같은 날 돈이 2일 때 `TakeSheet`는 허용되어 돈 0.
- 범위 밖: 종이 미리 사두기, 색·크기 선택.

### F-005 3D 자유 접기
- 목적: 손으로 종이를 끌어 접는 핵심 조작(시험판 계승, 가이드 없음).
- 관련 규칙: R-007, R-008
- 기대 동작: 시험판과 같다 — 모서리·변·면을 잡아(자석) 끌면 접힐 모습 미리보기, 놓으면 접힘 애니메이션 후 확정. Shift = 산접기. 뒤집기, 되돌리기(무제한), 다시 펴기, 시점 회전·확대. 튜토리얼 종이 외에는 목표 표시·정확도 점수·안내 문구가 **없다**.
- 엣지 케이스: 너무 짧은 끌기, 접히는 부분 없음, 접는 선이 종이 밖, 끄는 중 Esc, 접는 중 일어나기(종이는 그대로 남음), 뒤집기만 한 상태.
- 수용 기준:
  - AC-01 [Core]: `TakeSheet`, `Fold((−1,1),(−1,−1),false)` → 접은 횟수 1, 윤곽 = x ∈ [−1,1], y ∈ [−1,0] 직사각형(넓이 2.0), 모든 조각 넓이 합 4.0.
  - AC-02 [Core]: 이어서 `Undo` → 접은 횟수 0, 윤곽 넓이 4.0. 다시 `Undo` → 거부(NothingToUndo).
  - AC-03 [Core]: `Fold((−1,1),(−1,0.98))`(끌기 0.02) → 거부(InvalidFold). `Fold((−1,1),(−3,3))`(접는 선이 종이 밖) → 거부(InvalidFold). 두 경우 접은 횟수 0.
  - AC-04 [Core]: `Fold((−1,1),(−1,−1))`, `Flip` → 접은 횟수 1, 윤곽 넓이 2.0. `Undo` → 뒤집기만 취소(접은 횟수 1, 뒤집기 전과 같은 조각 좌표).
  - AC-05 [Core]: 접기 3회 후 `Unfold` → 접은 횟수 0, 조각 1, 윤곽 넓이 4.0, 이어서 `Undo` → 거부(NothingToUndo), `Unfold` → 거부(NothingToUndo).
  - AC-06 [Core]: 같은 grab·drop으로 산접기와 골접기를 하면 윤곽이 같고, 넘어간 조각의 겹 순서는 골접기 = 맨 위, 산접기 = 맨 아래다.
  - AC-07 [Core]: 접은 횟수 2인 상태에서 `Stand`, `Sit` → 접은 횟수 2, 조각 좌표 동일, `Undo` 가능.
  - AC-08 [Core]: 종이가 없을 때 `Fold`/`Flip`/`Undo`/`Unfold` → 거부(NoSheet).
  - AC-09 [Core]: 튜토리얼 종이가 아닌 종이에서는 어떤 접기 후에도 가이드 보임 = 거짓, 단계 점수 없음.
  - AC-10 [Unity]: 마우스 왼쪽으로 종이 모서리 0.16 안을 누르면 모서리가 잡히고, 끄는 동안 미리보기가 보이며, 놓으면 접힘 애니메이션 후 Core 접은 횟수가 1 증가한다. 끄는 중 Esc → 접은 횟수 변화 없음.
  - AC-11 [Unity] (사용자 플레이테스트): 시험판과 같은 조작감(사용자 확인).
- 범위 밖: 한 겹만 접기 등 페이즈 2 기법, 종이 회전·이동.

### F-006 튜토리얼 (첫 종이만 가이드)
- 목적: 처음 한 번만 조작을 가르치고, 그 뒤는 책으로 스스로.
- 관련 규칙: R-008
- 기대 동작: 런의 첫 종이에서 종이비행기 5단계 가이드(노란 공·초록 원·빨간 점선·단계 제목·단계 점수). 첫 종이를 완성/버리면 튜토리얼 끝. 그 밖에 걷기 안내 문구(F-013)는 첫 앉기 전까지.
- 엣지 케이스: 가이드 끄기, 되돌리기·다시 펴기로 단계 되돌림, 가이드와 다른 모양 접기, 첫 종이를 버림.
- 수용 기준:
  - AC-01 [Core]: 첫 `TakeSheet` 후 가이드 단계 1, 목표 잡기 (−1,1), 놓기 (0,0).
  - AC-02 [Core]: plane 1단계를 정확히 접으면 단계 점수 100, 가이드 단계 2. `Undo` → 가이드 단계 1, 단계 점수 기록 0개.
