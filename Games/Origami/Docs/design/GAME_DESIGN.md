# Origami 게임 기획

> 담당: game-designer · 기준 태스크: ORIGAMI-001 (첫 플레이 가능 버전)

## 콘셉트 (한 줄)
일주일(7일) 동안 도안을 외워 종이를 순서대로 접고, 완성한 작품을 저녁 장터에 팔아 돈을 모으며, 마지막 날 **무엇을 접었는지와 얼마를 벌었는지**에 따라 다른 엔딩을 보는 작은 종이접기 가게 시뮬레이션.

## 핵심 재미
- **외워서 접는 손맛**: 접기 전에 도안(접는 순서)을 보고, 접는 동안에는 도안이 가려진다. 순서를 기억해 방향키로 한 단계씩 접는다. 단계가 긴 작품일수록 어렵고 비싸다.
- **위험과 보상**: 틀리면 품질이 떨어지고, 3번 틀리면 종이를 망친다(종이값 손해). 힌트는 안전하지만 품질을 깎는다.
- **성장**: 쉬운 작품을 여러 번 완성하면 더 어렵고 비싼 작품이 해금된다(종이비행기·종이배 → 개구리 → 학 → 용).
- **엔딩 목표 고르기**: 돈을 최대로 벌지(종이 재벌), 학만 잔뜩 접을지(학의 소원), 모든 작품을 완벽하게 접어 볼지(종이접기 명인) 플레이어가 고른다.

## 타깃 경험
- 1회 플레이 10~20분. 처음 보는 사람도 첫 작품(3~4단계)을 1분 안에 완성할 수 있다.
- 실력이 늘수록 긴 도안(8~10단계)을 힌트 없이 외워 완벽(★3) 등급을 받는 성취감.
- 운 요소 없음: 같은 입력이면 항상 같은 결과(결정적). 실력과 선택만 결과를 바꾼다.

## 핵심 게임 루프
1. **아침**: 하루 시작. 오늘의 인기 작품(판매가 ×1.5)을 확인한다.
2. **작업**: 해금된 작품 중 하나를 골라 도안을 미리 본다 → 종이를 사서(종이값 지불) 접기 시작 → 도안이 가려진 상태에서 단계를 순서대로 입력 → 완성(등급 ★1~★3) 또는 망침/포기. 하루에 종이는 최대 5장까지 시도할 수 있다.
3. **저녁 장터**: 플레이어가 "하루 마치기"를 누르면 오늘 완성한 작품이 모두 자동으로 팔리고 돈이 들어온다.
4. 1~3을 7일 반복한다. 도중에 돈이 0이 되어 종이를 살 수 없으면 즉시 파산으로 끝난다.
5. **엔딩**: 7일째 정산 후(또는 파산 시) 최종 돈과 작품 기록으로 5개 엔딩 중 하나가 정해지고 결과 화면을 보여 준다.

세부 수치·규칙은 `GAME_RULES.md`(R-001~R-015), 기능 명세는 `FEATURE_SPECS.md`(F-001~F-007), 작품·수요·엔딩 표는 `CONTENT_SPECS.md`를 따른다.

## 진행/성장 구조
- **작품 해금 사슬**: 종이비행기·종이배(처음부터) → 종이배 3개 완성 시 개구리 → 개구리 3개 완성 시 학 → 학 3개 완성 시 용. 한 런(7일) 안에서만 유지된다.
- **돈**: 종이값을 내고 남은 돈이 다음 날 작업 자금이 된다. 돈은 당일 저녁에야 들어오므로 아침 자금 안에서 종이를 사야 한다.
- 런 사이에 이어지는 성장·저장은 없다. 매 런은 같은 초기 상태에서 시작한다.

## 범위 (하지 않을 것 포함)
- 포함: 7일 진행, 하루 시도 5회, 작품 5종, 단계 입력(5종 동작), 실수·힌트·망침·포기, 등급 3단계, 해금 사슬, 요일별 인기 작품, 저녁 자동 판매, 파산, 엔딩 5종, 결과 화면, 다시 시작.
- 그래픽: 코드로 그린 단순 도형(사각형 종이, 다각형 작품 아이콘, 색상)과 텍스트만. 아트 에셋 없음.
- 제외(첫 버전): 무작위 요소(손님·수요 변동 없음), 제한 시간/타이머, 손님 개별 주문, 재고 보관(작품은 당일 전부 판매), 종이 종류·색 선택, 업그레이드/도구 상점, 저장/불러오기, 최고 기록 저장, 사운드 요구사항, 온라인 기능, 실제 종이 접힘 물리 시뮬레이션.
