# Origami 게임 규칙 (v2)

> 담당: game-designer · 기준 태스크: ORIGAMI-007 · v1 규칙(ORIGAMI-001의 R-001~R-015)은 이 문서로 **대체**되었다(맨 아래 "v1 규칙 처리" 표).
> 작품별 기준 접기 순서·가격·인기 작품·엔딩 문구·방 배치는 `CONTENT_SPECS.md`가 기준이다.

## 기본 수치

| 이름 | 값 | 설명 |
|---|---|---|
| TOTAL_DAYS | 7 | 1일차 ~ 7일차 |
| START_MONEY | 20 | 런 시작 돈(정수, 음수 불가) |
| PAPER_COST | 2 | 종이 한 장 값(모든 작품 동일) |
| DAILY_SHEETS | 5 | 하루에 꺼낼 수 있는 종이 수(무료 튜토리얼 종이 포함) |

| GRADE3_MIN / GRADE2_MIN | 95 / 90 (%) | ★3 / ★2 최소 일치도. 85~89 = ★1 |
| GRADE_PCT | ★3 150 · ★2 100 · ★1 60 | 등급 판매 배율(%) |
| POPULAR_PCT / NORMAL_PCT | 150 / 100 | 그날 인기 작품 / 그 밖 |

| PAPER_SIZE | 한 변 2 (종이 좌표) = 20cm | 종이 좌표: 중심 (0,0), x 오른쪽, y 앉은 사람에게서 먼 쪽, 1 = 10cm |
| MATCH_ERROR_MAX | 0.005 | 일치도(IoU) 계산값과 정확값의 허용 오차(구현 방법은 architect 결정) |
| WALK_SPEED | 3.0 m/s | 캐릭터 걷기 속도 |
| INTERACT_RANGE | 1.2 m | 상호작용 지점과 캐릭터 사이 수평 거리 이하일 때 상호작용 가능 |

접기 입력 상수(잡기 자석 모서리 0.16·변 0.08, 놓기 꼭짓점 자석 0.06, 최소 끌기 0.03, 튜토리얼 목표 자석 0.08, 애니메이션 시간)는 Fold3DSpike 값을 기본으로 하고 architect가 조정할 수 있다. 이 값들은 판정 규칙에는 들어가지 않는다(판정은 확정된 종이 상태만 본다).

## 명령 (Core 규칙 입력)

| 명령 | 뜻 |
|---|---|
| `NewRun` | 새 런 시작 |
| `Interact(t)` | 걷기 중 대상 t ∈ {table, bookshelf, counter, bed} 사용 (범위 검사는 Runtime, R-004) |
| `StandUp` | 테이블에서 일어나기 |
| `OpenBook` / `CloseBook` / `TurnPage(쪽)` | 앉은 상태에서 책 펴기 / 책 닫기 / 쪽 이동 |
| `BuyPage(m)` | 작품 m의 책 페이지 사기 |
| `CloseCounter` | 판매대 화면 닫기 |
| `Sleep(yes/no)` | 잠자기 확인 응답 |
| `TakeSheet` | 종이 꺼내기 |
| `Fold(grab, drop, mountain)` | 잡은 점 grab을 drop에 놓아 접기(mountain = 산접기) |
| `Flip` · `Undo` · `Unfold` | 종이 뒤집기 · 되돌리기 · 처음 상태로 다시 펴기 |
| `Finish` · `Discard` | 완성(판정) · 버리기 |
| `SkipGuide` | 튜토리얼 가이드 끄기 |

## 규칙 목록

### R-001 결정성
- 설명: 게임 규칙 상태는 위 명령만으로 바뀐다. 규칙 로직은 현재 시각·프레임 시간·난수를 쓰지 않는다. 인기 작품은 고정 표.
- 기대 동작: 같은 초기 상태에 같은 명령 열을 적용하면 Unity 없이도 최종 상태(돈, 일차, 모드, 종이 상태, 기록, 엔딩)가 같다.
- 예외 상황: 걷기 이동·카메라·애니메이션은 프레임 시간을 쓰는 표현 계층이며 규칙 상태(돈·일차 등)를 바꾸지 않는다. 이후 무작위 요소를 넣으면 런 시작 시 명시적 시드를 입력으로 받는다.

### R-002 런 시작 상태
- 설명: `NewRun` → 일차 1, 돈 20, 오늘 남은 종이 5, 보유 페이지 {plane, house}, 첫 종이 무료 남음(튜토리얼 대기), 모드 걷기, 테이블 위 종이 없음, 책 닫힘, 오늘 진열 작품 없음, 작품별·등급별 완성 수 0, 실패 수 0, 총 판매액 0, 총 종이값 0, 총 책값 0, 런 종료 아님, 엔딩 없음.
- 기대 동작: 언제 호출해도 이전 런과 무관하게 위 상태가 된다(진행 중인 종이·진열 작품은 버려지고 엔딩 판정 없음).
- 예외 상황: 런 종료 후에도 허용되는 유일한 명령이다.

### R-003 공방 모드
- 설명: 모드는 걷기 / 앉음 / 책장 읽기 / 판매대 보기 / 잠자기 확인 / 종료 중 하나. 앉음에는 "책 펼침" 여부가 따로 있다.

| 현재 모드 | 명령 | 결과 모드 |
|---|---|---|
| 걷기 | `Interact(table)` | 앉음(책 닫힘) |
| 걷기 | `Interact(bookshelf)` | 책장 읽기 |
| 걷기 | `Interact(counter)` | 판매대 보기 |
| 걷기 | `Interact(bed)` | 잠자기 확인 (테이블에 종이가 있으면 거부 SheetOnTable) |
| 앉음 | `StandUp` | 걷기 (책 펼침 → 닫힘, 테이블 위 종이는 그대로 남음) |
| 앉음 | `OpenBook` / `CloseBook` | 앉음 (책 펼침 / 닫힘) |
| 책장 읽기 | `CloseBook` | 걷기 |
| 판매대 보기 | `CloseCounter` | 걷기 |
| 잠자기 확인 | `Sleep(no)` | 걷기 |
| 잠자기 확인 | `Sleep(yes)` | 하루 정산(R-016) 후 걷기(새 날) 또는 종료 |

- 기대 동작: 걷기 모드에서만 캐릭터가 움직인다. 앉음에서 책을 펴도 접기 명령은 계속 받는다(책을 보며 접기).
- 예외 상황:
  - 표와 다른 규칙(R-006~R-009, R-014)에 없는 모드·명령 조합은 거부(WrongMode). 예: 앉음에서 `Interact`, 걷기에서 `TakeSheet`, 책장 읽기에서 `Fold`, 걷기에서 `OpenBook`.
  - 앉음에서 책이 이미 펴져 있을 때 `OpenBook`, 닫혀 있을 때 `CloseBook`은 거부가 아니라 변화 없이 허용(멱등).
  - `TurnPage`는 책이 보일 때(책장 읽기, 앉음+책 펼침)만 허용, 그 밖은 WrongMode.

### R-004 상호작용 범위 (Runtime)
- 설명: 걷기 중 캐릭터와 각 대상의 상호작용 지점(`CONTENT_SPECS.md` §6) 사이 수평 거리가 INTERACT_RANGE(1.2m) 이하인 대상만 상호작용 후보다. 후보가 여럿이면 가장 가까운 대상, 거리가 같으면 table > bookshelf > counter > bed 순.
- 기대 동작: 후보가 있으면 화면에 "E: 앉기 / 책 읽기 / 판매대 보기 / 잠자기" 안내, E 키로 `Interact(후보)`.
- 예외 상황: 후보가 없으면 E는 아무 일도 하지 않는다. Core는 범위를 검사하지 않는다(Runtime 책임).

### R-005 하루 구조
- 설명: 하루는 `Sleep(yes)`로만 끝난다. 하루 동안 종이를 최대 5장 꺼낼 수 있다.
- 기대 동작: 종이를 다 써도 자동으로 끝나지 않는다. 종이를 한 장도 쓰지 않고 잘 수 있다.
- 예외 상황: 테이블 위에 종이가 있으면 침대 상호작용이 거부(SheetOnTable)된다(완성하거나 버려야 잘 수 있다).

### R-006 종이 꺼내기
- 설명: 앉음 모드에서 `TakeSheet` → 테이블에 접히지 않은 정사각형 종이(흰 면 위)가 놓인다. 런의 첫 종이면 무료(튜토리얼 종이, R-008), 아니면 돈 −2, 총 종이값 +2. 오늘 남은 종이 −1(무료 종이 포함).
- 기대 동작: 종이값은 환불되지 않는다.
- 예외 상황 — 이 순서로 검사해 첫 사유로 거부, 상태 불변: RunEnded → WrongMode → SheetOnTable(이미 종이 있음) → NoSheetsLeft(남은 종이 0) → NotEnoughMoney(유료 종이이고 돈 < 2; 돈 = 2면 허용, 돈 0).

### R-007 접기 동작 (Fold3DSpike 규칙 계승)
- 설명:
  - `Fold(grab, drop, mountain)`: 접는 선 = grab과 drop을 잇는 선분의 수직이등분선. 선을 기준으로 grab 쪽의 **모든 겹**이 180° 넘어가 반대쪽에 평평하게 놓인다. 골접기는 넘어간 부분이 맨 위, 산접기는 맨 아래로 간다. 접힌 부분은 앞뒤 면이 바뀐다.
  - `Flip`: 종이 전체를 좌우로 뒤집는다(윤곽 가로 범위의 가운데 세로선 기준).
  - `Undo`: 마지막 `Fold` 또는 `Flip` 하나를 취소. 횟수 제한 없음.
  - `Unfold`: 종이를 처음(접기 0회, 흰 면 위) 상태로 되돌리고 되돌리기 기록을 비운다. 비용 없음.
- 기대 동작: "현재 접은 횟수" = 현재 상태에 적용된 `Fold` 수(`Undo`된 접기 제외, `Unfold` 후 0). `Flip`은 세지 않는다.
- 예외 상황 — 공통 검사 순서 RunEnded → WrongMode(앉음 아님) → NoSheet. 그 뒤:
  - `Fold`: 끌기 거리 < 0.03, 움직이는 부분 없음, 남는 부분 없음(접는 선이 종이 밖) → 거부(InvalidFold), 상태 불변.
  - `Undo`, `Unfold`: 되돌릴 기록이 없으면 거부(NothingToUndo).

### R-008 튜토리얼 가이드 (첫 종이만)
- 설명: 런의 첫 `TakeSheet`로 나온 종이가 튜토리얼 종이다. 이 종이가 테이블에 있는 동안, 가이드를 끄지 않았고 현재 접은 횟수 k < 5이면 종이비행기 k+1단계 가이드(잡을 곳 노란 공, 놓을 곳 초록 원, 이상적인 접는 선 빨간 점선, 단계 제목)를 보여 준다.
- 기대 동작: 접기를 확정할 때마다 시험판과 같은 단계 정확도(0~100점)를 보여 준다(피드백 전용, 등급·가격에 영향 없음). `Undo`/`Unfold`하면 가이드 단계도 현재 접은 횟수에 맞춰 돌아간다. 놓을 곳 자석(0.08)은 가이드가 보이는 동안만 작동한다.
- 예외 상황:
  - `SkipGuide` → 이 종이의 가이드가 사라지고 다시 켤 수 없다. 종이는 여전히 무료. 가이드가 보이지 않을 때 `SkipGuide` → 거부(NoGuide).
  - 튜토리얼 종이를 `Finish`/`Discard`하면 튜토리얼이 끝난다. 이후 이 런에서 어떤 종이에도 가이드가 나오지 않는다(다시 시도해도).
  - 튜토리얼 종이로 종이비행기가 아닌 모양을 만들어도 일반 판정(R-012)을 따른다.
  - 첫 종이를 2일차 이후에 꺼내도 그것이 튜토리얼 종이다.

### R-009 완성 · 버리기
- 설명:
  - `Finish`: 현재 종이를 판정(R-011~R-013)한다. 작품이면 (작품, 등급, 일치도)를 오늘 진열 목록에 추가하고 그 작품의 등급별 완성 수 +1. 작품이 아니면 "구겨진 종이": 실패 수 +1, 진열 안 됨. 어느 쪽이든 종이는 테이블에서 사라진다.
  - `Discard`: 판정 없이 실패 수 +1, 종이가 사라진다.
- 기대 동작: 돈은 완성 시 바뀌지 않는다(저녁 정산에서 들어온다).
- 예외 상황 — RunEnded → WrongMode → NoSheet → (`Finish`만) NoFolds(현재 접은 횟수 0). 

### R-010 책 열람
- 설명: 책은 책장 읽기 모드 또는 앉음+책 펼침에서만 보인다. 책은 쪽의 나열이다: [목차] + 작품마다 카탈로그 순서로 [표지, 1단계, …, N단계, 완성]. 두 쪽씩 펼쳐 보인다. 목차에서 작품을 고르면 그 작품의 표지로 간다.
- 기대 동작: 보유한 작품은 모든 쪽을 볼 수 있다. 보유하지 않은 작품은 표지(실루엣·이름·난이도·접는 횟수·기본가·페이지 가격·구입 버튼)만 보이고 단계 쪽은 "봉인됨"으로 보인다.
- 예외 상황: 첫 쪽에서 이전, 마지막 쪽에서 다음은 무시(쪽 유지). 책을 닫았다 다시 열면 마지막으로 보던 쪽이 열린다(런 안에서 유지, `NewRun` 시 목차).

### R-011 윤곽 일치도
- 설명: 두 종이 상태 A(플레이어), B(작품 기준 = 그 작품의 기준 접기 순서를 처음 종이에 정확히 적용한 결과)의 일치도:
  1. 각 상태의 **윤곽** = 모든 조각을 위에서 본 다각형들의 합집합(겹 수·앞뒤 면·산/골 무시).
  2. 각 윤곽을 넓이 무게중심이 (0,0)이 되도록 평행이동.
  3. B 윤곽에 정사각형 대칭 8가지(0°/90°/180°/270° 회전, 그리고 각각 x → −x 좌우 반전)를 적용한 각각에 대해 IoU = 넓이(A ∩ gB) ÷ 넓이(A ∪ gB).
  4. 일치도 s = 8개 IoU의 최댓값(0~1). 일치도 % = floor(s × 100 + 1e-9)(부동소수 오차 보정).
- 기대 동작: 접는 순서, 어느 쪽 모서리부터 접었는지, 종이를 뒤집었는지, 종이의 테이블 위 위치는 결과에 영향이 없다. 기준 순서를 정확히 따르면 s = 1(계산 오차 MATCH_ERROR_MAX 이내).
- 예외 상황: 계산 방법(정확한 다각형 연산 또는 격자 샘플링)은 architect가 정하되 `CONTENT_SPECS.md` §4 기준값과 ±0.01 이내여야 한다.

### R-012 작품 판정과 등급
- 설명: 후보(R-013) 각각의 일치도 중 최댓값인 작품을 고른다(같으면 카탈로그 순서가 앞선 작품). 그 일치도 %가
  - 95 이상 → ★3, 90~94 → ★2, 85~89 → ★1, 85 미만 → 구겨진 종이(작품 아님).
- 기대 동작: 결과 화면에 "작품 이름 ★n (일치도 xx%)" 또는 "구겨진 종이 (가장 비슷한 작품: 이름 xx%)"를 보여 준다.
- 예외 상황: 후보가 없을 수 없다(plane, house는 항상 보유).

### R-013 판정 후보
- 설명: 판정 후보 = 완성 시점에 보유한 책 페이지의 작품. 보유하지 않은 작품 모양은 후보가 아니다.
- 기대 동작: 페이지를 산 직후 완성한 종이부터 그 작품이 후보가 된다.
- 예외 상황: 보유하지 않은 작품을 정확히 접어도, 보유 작품 중 일치도가 85% 이상인 것이 없으면 구겨진 종이다.

### R-014 책 페이지 구입
- 설명: 책이 보이는 상태(책장 읽기 또는 앉음+책 펼침)에서 `BuyPage(m)` → 돈 −페이지 가격, 총 책값 +가격, m 보유.
- 기대 동작: 즉시 m의 단계 쪽을 볼 수 있고 판정 후보가 된다. 런 끝까지 유지.
- 예외 상황 — RunEnded → WrongMode(책이 보이지 않음) → UnknownModel(없는 ID, 빈 문자열, null) → AlreadyOwned → NotEnoughMoney(돈 = 가격이면 허용, 돈 0). 종이를 접는 중에도 살 수 있다(앉음+책 펼침).

### R-015 판매 가격
- 설명: 작품 1개 판매가 = `floor(기본가 × GRADE_PCT × 수요PCT / 10000)`, 수요PCT = 판매일의 인기 작품이면 150, 아니면 100.
- 기대 동작: 예) 강아지(18) ★3 인기 → floor(18×150×150/10000) = 40. 글라이더(26) ★2 일반 → 26.
- 예외 상황: 인기 작품의 페이지가 없어도 표는 바뀌지 않는다.

### R-016 하루 정산 (잠자기)
- 설명: `Sleep(yes)` → 오늘 진열 목록의 모든 작품을 R-015 가격으로 팔아 합계를 돈과 총 판매액에 더하고 목록을 비운다. 그다음
  - 일차가 7이면 런 종료(완주). 일차 7 유지.
  - 아니면 일차 +1, 오늘 남은 종이 5, 모드 걷기(캐릭터는 침대 옆 시작 위치), 파산 검사(R-017).
- 기대 동작: 정산 내역(작품별 등급·가격, 합계, 정산 후 돈)을 정산 화면에 보여 준다.
- 예외 상황: 진열 0개 → 합계 0.

### R-017 파산
- 설명: 새 날이 시작될 때(R-016 일차 +1 직후) 돈 < PAPER_COST(2)이면 즉시 런 종료(파산). 일차는 새 날 값.
- 기대 동작: 낮 동안 돈이 0이 되어도 파산이 아니다. 돈 = 2면 파산 아님.
- 예외 상황: 7일차 정산 후에는 검사하지 않는다. 무료 튜토리얼 종이가 아직 남아 있어도 검사는 같다.

### R-018 엔딩 판정
- 설명: 런 종료 시 위에서부터 검사해 처음 만족하는 엔딩 하나.

| 우선순위 | ID | 이름 | 조건 |
|---|---|---|---|
| 1 | E-01 | 빈손 | 종료 사유 파산 **또는** 최종 돈 ≤ 20 |
| 2 | E-02 | 튤립 꽃밭 | 튤립 완성 수(등급 무관) ≥ 12 |
| 3 | E-03 | 종이접기 명인 | 5종 작품 각각 ★3 완성 수 ≥ 1 |
| 4 | E-04 | 종이 재벌 | 최종 돈 ≥ 600 |
| 5 | E-05 | 동네 종이접기 공방 | 위 모두 불만족 |

- 기대 동작: 입력은 종료 사유, 최종 돈, 작품별·등급별 완성 수뿐(순수 함수). 한 번 정해지면 바뀌지 않는다.
- 예외 상황: `NewRun`으로 중단한 런은 판정하지 않는다. 구겨진 종이·버린 종이는 완성 수가 아니다.

### R-019 명령 거부 일반 규칙
- 설명: 규칙에 맞지 않는 명령은 예외로 멈추지 않고 거부되며 상태를 전혀 바꾸지 않는다. 사유: RunEnded, WrongMode, UnknownTarget, SheetOnTable, NoSheetsLeft, NotEnoughMoney, NoSheet, InvalidFold, NothingToUndo, NoFolds, NoGuide, UnknownModel, AlreadyOwned.
- 기대 동작: 모든 명령은 먼저 RunEnded(런 종료 후, `NewRun` 제외), 다음 WrongMode를 검사한다. 이후 순서는 각 규칙에 적힌 대로.
- 예외 상황: `Interact(t)`의 t가 네 대상이 아니면(null 포함) UnknownTarget(WrongMode 다음).

### R-020 기록
- 설명: 런 기록 = 최종 돈, 작품별·등급별 완성 수, 실패 수(구겨진 종이 + 버린 종이), 총 판매액, 총 종이값, 총 책값, 보유 페이지. 결과 화면에 표시.
- 기대 동작: 돈 = 20 + 총 판매액 − 총 종이값 − 총 책값이 항상 성립한다.
- 예외 상황: 없음.

## 승리 / 패배
- 명확한 승패 없음. 런은 7일차 잠자기(완주) 또는 새 날 아침 돈 < 2(파산)로 끝나고 엔딩 1개 + 기록으로 평가한다. E-01이 사실상 패배, E-02~E-04가 목표형, E-05가 보통 엔딩.
