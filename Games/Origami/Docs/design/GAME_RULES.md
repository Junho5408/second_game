# Origami 게임 규칙

> 담당: game-designer · 기준 태스크: ORIGAMI-001

## 기본 수치

| 이름 | 값 | 설명 |
|---|---|---|
| 총 일수 (TOTAL_DAYS) | 7 | 1일차 ~ 7일차 |
| 시작 돈 (START_MONEY) | 20 | 런 시작 시 보유 돈(정수, 단위 "원" 표기는 UI 자유) |
| 하루 시도 횟수 (DAILY_ATTEMPTS) | 5 | 하루에 접기를 **시작**할 수 있는 최대 횟수(완성·망침·포기 모두 1회 소모) |
| 실수 한도 (MISTAKE_LIMIT) | 3 | 한 번의 접기에서 실수가 이 값에 **도달하면** 종이를 망친다 |
| 실수 벌점 (MISTAKE_PENALTY) | 2 | 실수 1회당 벌점 |
| 힌트 벌점 (HINT_PENALTY) | 1 | 힌트를 본 단계 1개당 벌점 |
| 인기 작품 배율 (POPULAR_PCT) | 150 (%) | 그날의 인기 작품 판매가 배율 |
| 일반 배율 (NORMAL_PCT) | 100 (%) | 인기 작품이 아닌 작품 |
| 해금 필요 수 (UNLOCK_COUNT) | 3 | 선행 작품 완성 개수(등급 무관) |
| 엔딩: 재벌 기준 (TYCOON_MONEY) | 1000 | 최종 돈 이 값 **이상** |
| 엔딩: 학 기준 (CRANE_COUNT) | 15 | 학 완성 개수(등급 무관) 이 값 **이상** |

### 등급 (벌점 = 실수 수 × 2 + 힌트 본 단계 수)

| 등급 | 벌점 | 등급 배율 (GRADE_PCT) |
|---|---|---|
| ★3 완벽 | 0 | 150 |
| ★2 좋음 | 1 ~ 2 | 100 |
| ★1 보통 | 3 이상 | 60 |

### 접기 동작 (5종)

| 기호 | 이름 | 권장 키 | 화면 버튼 |
|---|---|---|---|
| U | 위로 접기 | ↑ 또는 W | 있음 |
| D | 아래로 접기 | ↓ 또는 S | 있음 |
| L | 왼쪽으로 접기 | ← 또는 A | 있음 |
| R | 오른쪽으로 접기 | → 또는 D | 있음 |
| F | 뒤집기 | Space | 있음 |

보조 동작: 힌트(H 키/버튼), 포기(Esc 키/버튼). 작품별 단계 순서·종이값·기본가·해금 조건은 `CONTENT_SPECS.md` 표가 기준이다.

## 규칙 목록

### R-001 결정성 (시계·난수 없음)
- 설명: 게임 규칙은 플레이어 명령(접기 시작, 동작 입력, 힌트, 포기, 하루 마치기, 새 런)만으로 상태가 바뀐다. 규칙 로직은 현재 시각을 읽지 않고 난수를 쓰지 않는다. 시간 제한·타이머도 없다. 인기 작품은 일차별 고정 표(`CONTENT_SPECS.md`)로 정한다.
- 기대 동작: 같은 명령 열을 같은 초기 상태에 적용하면 언제 어디서 실행해도(Unity 없이도) 최종 상태가 완전히 같다.
- 예외 상황: 이후 버전에서 무작위 요소를 넣는다면 반드시 런 시작 시 명시적 시드를 입력으로 받아야 한다(이 버전에는 없음).

### R-002 런 시작 상태
- 설명: 새 런은 다음 상태로 시작한다: 일차 1, 돈 20, 오늘 남은 시도 5, 해금 작품 {종이비행기, 종이배}, 모든 작품 완성 수 0(등급별 0), 실패(망침+포기) 수 0, 총 판매액 0, 총 종이값 0, 오늘 완성 작품 목록 비어 있음, 접는 중 아님, 런 종료 아님, 엔딩 없음.
- 기대 동작: "다시 시작"(새 런)은 이전 런과 무관하게 항상 위 상태를 만든다.
- 예외 상황: 런 도중에도 새 런 명령은 허용되며 진행 중 접기·오늘 작품은 모두 버려진다(판매되지 않음).

### R-003 하루 구조
- 설명: 하루 동안 플레이어는 접기를 최대 `DAILY_ATTEMPTS`(5)회 시작할 수 있다. 하루는 플레이어의 "하루 마치기" 명령으로만 끝난다(시도를 다 써도 자동으로 끝나지 않음).
- 기대 동작: 하루 마치기 → 정산(R-012) → 다음 날 시작 시 남은 시도는 5로 초기화된다.
- 예외 상황: 시도를 하나도 쓰지 않고 하루를 마칠 수 있다(정산 금액 0). 접는 중에는 하루를 마칠 수 없다(거부, 상태 불변).

### R-004 접기 시작 (종이 구매)
- 설명: 작품을 골라 접기를 시작하면 즉시 그 작품의 종이값을 돈에서 빼고, 오늘 남은 시도를 1 줄이고, 해당 작품의 1단계부터 입력을 기다린다(진행 단계 0, 실수 0, 힌트 0).
- 기대 동작: 종이값은 환불되지 않는다(완성·망침·포기 모두).
- 예외 상황 — 아래 조건을 **이 순서로** 검사하여 처음 걸리는 사유로 거부하고 상태를 바꾸지 않는다:
  1. 런 종료됨 (RunEnded)
  2. 이미 접는 중 (FoldInProgress)
  3. 존재하지 않는 작품 ID (UnknownModel) — 빈 문자열과 null(ID 없음)도 여기에 해당한다.
  4. 잠긴 작품 (Locked)
  5. 오늘 남은 시도 0 (NoAttemptsLeft)
  6. 돈 < 종이값 (NotEnoughMoney) — 돈 = 종이값이면 허용, 돈은 0이 된다. 돈은 절대 음수가 되지 않는다.

### R-005 동작 입력
- 설명: 접는 중에 동작(U/D/L/R/F) 하나를 입력하면 현재 단계의 정답과 비교한다.
  - 정답: 진행 단계 +1. 마지막 단계까지 맞히면 즉시 완성(R-009).
  - 오답: 실수 +1, 진행 단계는 그대로(같은 단계를 다시 입력). 실수가 `MISTAKE_LIMIT`(3)에 도달하면 망침(R-007).
- 기대 동작: 접는 동안 도안(전체 순서)은 보이지 않고, 이미 맞힌 단계의 기호만 보인다.
- 예외 상황: 접는 중이 아닐 때(완성·망침·포기 직후 포함)나 런 종료 후의 동작 입력은 거부(NoFold/RunEnded), 상태 불변.
- 예외 상황(정의되지 않은 동작): U/D/L/R/F 5종이 아닌 동작 값(예: 정의되지 않은 열거 값)은 거부(InvalidAction), 상태 불변. **실수로 세지 않는다**(실수는 5종 동작 중 정답이 아닌 것을 입력했을 때만 +1). 검사 순서는 RunEnded → NoFold → InvalidAction이다(접는 중이 아니면 NoFold가 먼저).

### R-006 힌트
- 설명: 접는 중 힌트를 쓰면 **현재 단계**의 정답 기호를 보여 준다. 힌트를 본 단계 수가 +1 된다.
- 기대 동작: 같은 단계에서 힌트를 여러 번 눌러도 1회로만 센다. 힌트로 보인 기호는 그 단계를 맞힐 때까지 계속 보인다. 다음 단계로 넘어가면 새로 힌트를 써야 한다.
- 예외 상황: 접는 중이 아닐 때 힌트는 거부, 상태 불변. 힌트 수에는 상한이 없으며 힌트만으로는 망치지 않는다(등급만 내려감).

### R-007 망침
- 설명: 한 번의 접기에서 실수가 3이 되는 순간 종이를 망친다. 접기가 끝나고 작품은 생기지 않으며 실패 수 +1.
- 기대 동작: 종이값과 시도 1회는 이미 소모된 상태로 남는다. 완성 수·해금 진행에 반영되지 않는다.
- 예외 상황: 실수 2인 상태에서 마지막 단계를 맞히면 망치지 않고 완성된다(실수 2, 벌점 4 → ★1).

### R-008 포기
- 설명: 접는 중 언제든(진행 단계 0 포함) 포기할 수 있다. 결과는 망침과 같다(작품 없음, 실패 수 +1, 환불 없음).
- 예외 상황: 접는 중이 아닐 때 포기는 거부, 상태 불변.

### R-009 완성과 등급
- 설명: 마지막 단계를 맞히면 완성. 벌점 = 실수 × 2 + 힌트 본 단계 수로 등급을 정한다(★3: 0, ★2: 1~2, ★1: 3 이상). 완성 작품(작품 ID, 등급)이 오늘 완성 목록에 추가되고, 그 작품의 완성 수(등급별)가 +1 된다.
- 기대 동작: 완성 즉시 해금 검사(R-010)를 한다. 돈은 완성 시점에 바뀌지 않는다(저녁 정산에서 들어옴).
- 예외 상황: 실수 0·힌트 0만 ★3이다.

### R-010 해금
- 설명: 선행 작품의 누적 완성 수(등급 무관, 이번 런 기준)가 3에 도달하는 순간 다음 작품이 해금된다: 종이배 3 → 개구리, 개구리 3 → 학, 학 3 → 용.
- 기대 동작: 해금은 즉시 적용되어 같은 날 바로 그 작품을 시작할 수 있다. 한 번 해금되면 런 끝까지 유지된다.
- 예외 상황: 망침·포기는 세지 않는다. 종이비행기는 어떤 작품의 해금에도 쓰이지 않는다.

### R-011 판매 가격
- 설명: 작품 1개의 판매가 = `floor(기본가 × GRADE_PCT × 수요PCT / 10000)` (정수 연산, 내림). 수요PCT는 그 작품이 **판매되는 날**의 인기 작품이면 150, 아니면 100.
- 기대 동작: 예) 학(기본가 18) ★3, 인기 아님 → floor(18×150×100/10000) = 27. 학 ★3, 인기 → floor(40.5) = 40.
- 예외 상황: 인기 작품이 아직 잠겨 있어도 표는 바뀌지 않는다(그날 혜택을 못 받을 뿐).

### R-012 하루 정산 (저녁 장터)
- 설명: 하루 마치기 시 오늘 완성 목록의 모든 작품을 R-011 가격으로 판매하여 합계를 돈에 더하고, 목록을 비운다. 그다음:
  - 현재 일차가 7이면 런 종료(종료 사유: 완주). 일차는 7로 남는다.
  - 아니면 일차 +1, 남은 시도 5로 초기화한 뒤 파산 검사(R-013).
- 기대 동작: 정산 결과(작품별 가격, 합계, 정산 후 돈)를 화면에 보여 줄 수 있어야 한다.
- 예외 상황: 오늘 완성 작품이 없으면 합계 0. 런 종료 후 하루 마치기는 거부.

### R-013 파산
- 설명: 새 날이 시작될 때(R-012에서 일차 +1 직후) 돈이 해금된 작품 중 가장 싼 종이값(이 버전에서는 항상 종이비행기 1)보다 적으면, 즉 돈이 0이면 즉시 런 종료(종료 사유: 파산). 일차는 그 새 날 값으로 남는다.
- 기대 동작: 낮 동안 돈이 0이 되어도 즉시 파산하지 않는다(저녁 정산에서 돈이 들어올 수 있음). 파산 검사는 새 날 시작 시에만 한다.
- 예외 상황: 7일차 정산 후에는 파산 검사를 하지 않는다(완주로 종료, 엔딩 판정에서 돈 ≤ 20 조건이 처리).

### R-014 엔딩 판정
- 설명: 런이 종료되면 아래 표를 **위에서부터** 검사하여 처음 만족하는 엔딩 하나로 정한다(동시 만족 시 위가 우선).

| 우선순위 | ID | 이름 | 조건 |
|---|---|---|---|
| 1 | E-01 | 빈손 | 종료 사유가 파산 **또는** 최종 돈 ≤ 20 |
| 2 | E-02 | 학의 소원 | 학 완성 수(등급 무관) ≥ 15 |
| 3 | E-03 | 종이 재벌 | 최종 돈 ≥ 1000 |
| 4 | E-04 | 종이접기 명인 | 5종 작품 모두 ★3 완성 수 ≥ 1 |
| 5 | E-05 | 동네 종이접기 가게 | 위 조건 모두 불만족(기본) |

- 기대 동작: 판정 입력은 종료 사유, 최종 돈, 작품별·등급별 완성 수뿐이다. 엔딩은 런 종료 시 한 번 정해지고 바뀌지 않는다.
- 예외 상황: 새 런 명령(R-002)으로 중간에 그만둔 런은 엔딩을 판정하지 않는다.

### R-015 명령 거부 일반 규칙
- 설명: 규칙에 맞지 않는 명령은 예외·오류로 게임을 멈추지 않고 "거부"되며 상태를 전혀 바꾸지 않는다. 거부 사유는 UI가 안내 문구를 고를 수 있도록 구분 가능해야 한다(사유: RunEnded, FoldInProgress, UnknownModel, Locked, NoAttemptsLeft, NotEnoughMoney, NoFold, InvalidAction).
- 하루 마치기 거부 사유 검사 순서: RunEnded → FoldInProgress. 힌트/포기 거부 사유 검사 순서: RunEnded → NoFold. 동작 입력 거부 사유 검사 순서: RunEnded → NoFold → InvalidAction(R-005).

## 승리 / 패배 조건
- 명확한 승패는 없고 **엔딩 5종**으로 결과를 평가한다. 런은 (a) 7일차 하루 마치기(완주) 또는 (b) 새 날 시작 시 돈 0(파산)으로 끝난다.
- 결과 평가 = 엔딩 1개 + 기록(최종 돈, 작품별 완성 수와 등급 분포, 실패 수, 총 판매액, 총 종이값). 기록은 표시용이며 엔딩 판정에는 R-014 입력만 쓴다.
- E-01 빈손이 사실상의 "패배", E-02~E-04가 목표형 엔딩, E-05가 보통 엔딩이다.
