| `Fold(grab, drop, mountain, layers)` | 잡은 점 grab을 drop에 놓아 접기. mountain = 산접기, layers = 0(전체 겹) 또는 n ≥ 1(잡은 곳의 위 n겹) |

| `SkipGuide` | 튜토리얼 가이드 끄기 |

## 규칙 목록

### R-001 결정성
- 설명: 게임 규칙 상태는 위 명령만으로 바뀐다. 규칙 로직은 현재 시각·프레임 시간·난수를 쓰지 않는다. 인기 작품은 고정 표.
- 기대 동작: 같은 초기 상태에 같은 명령 열을 적용하면 Unity 없이도 최종 상태(돈, 일차, 모드, 종이 상태, 기록, 엔딩)가 같다.
- 예외 상황: 걷기 이동·카메라·애니메이션은 프레임 시간을 쓰는 표현 계층이며 규칙 상태(돈·일차 등)를 바꾸지 않는다. 이후 무작위 요소를 넣으면 런 시작 시 명시적 시드를 입력으로 받는다.

### R-002 런 시작 상태
- 설명: `NewRun` → 일차 1, 돈 20, 오늘 남은 종이 5, 보유 페이지 {plane, house}, 첫 종이 무료 남음(튜토리얼 대기), 모드 걷기, 테이블 위 종이 없음, 책 닫힘, 오늘 진열 작품 없음, 작품별·등급별 완성 수 0, 실패 수 0, 총 판매액 0, 총 종이값 0, 총 책값 0, 런 종료 아님, 엔딩 없음.
- 기대 동작: 언제 호출해도 이전 런과 무관하게 위 상태가 된다(진행 중인 종이·진열 작품은 버려지고 엔딩 판정 없음).
- 예외 상황: 런 종료 후에도 허용되는 유일한 명령이다.

### R-003 공방 모드
- 설명: 모드는 걷기 / 앉음 / 책장 읽기 / 판매대 보기 / 잠자기 확인 / 종료 중 하나. 앉음에는 "책 펼침" 여부가 따로 있다.

| 현재 모드 | 명령 | 결과 모드 |
|---|---|---|
| 걷기 | `Interact(table)` | 앉음(책 닫힘) |
| 걷기 | `Interact(bookshelf)` | 책장 읽기 |
| 걷기 | `Interact(counter)` | 판매대 보기 |
| 걷기 | `Interact(bed)` | 잠자기 확인 (테이블에 종이가 있으면 거부 SheetOnTable) |
| 앉음 | `StandUp` | 걷기 (책 펼침 → 닫힘, 테이블 위 종이는 그대로 남음) |
| 앉음 | `OpenBook` / `CloseBook` | 앉음 (책 펼침 / 닫힘) |
| 책장 읽기 | `CloseBook` | 걷기 |
| 판매대 보기 | `CloseCounter` | 걷기 |
| 잠자기 확인 | `Sleep(no)` | 걷기 |
| 잠자기 확인 | `Sleep(yes)` | 하루 정산(R-016) 후 걷기(새 날) 또는 종료 |

- 기대 동작: 걷기 모드에서만 캐릭터가 움직인다. 앉음에서 책을 펴도 접기 명령은 계속 받는다(책을 보며 접기).
- 예외 상황:
  - 표와 다른 규칙(R-006~R-009, R-014)에 없는 모드·명령 조합은 거부(WrongMode). 예: 앉음에서 `Interact`, 걷기에서 `TakeSheet`, 책장 읽기에서 `Fold`, 걷기에서 `OpenBook`.
  - 앉음에서 책이 이미 펴져 있을 때 `OpenBook`, 닫혀 있을 때 `CloseBook`은 거부가 아니라 변화 없이 허용(멱등).
  - `TurnPage`는 책이 보일 때(책장 읽기, 앉음+책 펼침)만 허용, 그 밖은 WrongMode.

### R-004 상호작용 범위 (Runtime)
- 설명: 걷기 중 캐릭터와 각 대상의 상호작용 지점(`CONTENT_SPECS.md` §6) 사이 수평 거리가 INTERACT_RANGE(1.2m) 이하인 대상만 상호작용 후보다. 후보가 여럿이면 가장 가까운 대상, 거리가 같으면 table > bookshelf > counter > bed 순.
- 기대 동작: 후보가 있으면 화면에 "E: 앉기 / 책 읽기 / 판매대 보기 / 잠자기" 안내, E 키로 `Interact(후보)`.
- 예외 상황: 후보가 없으면 E는 아무 일도 하지 않는다. Core는 범위를 검사하지 않는다(Runtime 책임).

### R-005 하루 구조
- 설명: 하루는 `Sleep(yes)`로만 끝난다. 하루 동안 종이를 최대 5장 꺼낼 수 있다.
- 기대 동작: 종이를 다 써도 자동으로 끝나지 않는다. 종이를 한 장도 쓰지 않고 잘 수 있다.
- 예외 상황: 테이블 위에 종이가 있으면 침대 상호작용이 거부(SheetOnTable)된다(완성하거나 버려야 잘 수 있다).

### R-006 종이 꺼내기
- 설명: 앉음 모드에서 `TakeSheet` → 테이블에 접히지 않은 정사각형 종이(흰 면 위)가 놓인다. 런의 첫 종이면 무료(튜토리얼 종이, R-008), 아니면 돈 −2, 총 종이값 +2. 오늘 남은 종이 −1(무료 종이 포함).
- 기대 동작: 종이값은 환불되지 않는다.
- 예외 상황 — 이 순서로 검사해 첫 사유로 거부, 상태 불변: RunEnded → WrongMode → SheetOnTable(이미 종이 있음) → NoSheetsLeft(남은 종이 0) → NotEnoughMoney(유료 종이이고 돈 < 2; 돈 = 2면 허용, 돈 0).

### R-007 접기 동작 (Fold3DSpike 규칙 계승 + 위 N겹 + 접었다 펴기)
- 설명:
  - **접는 선** = grab과 drop을 잇는 선분의 수직이등분선. grab이 있는 쪽이 "움직이는 쪽", 반대쪽이 "남는 쪽". 각 조각은 선에서 잘려 움직이는 쪽 부분과 남는 쪽 부분으로 나뉜다.
  - **전체 겹 접기** `Fold(grab, drop, mountain, 0)` (시험판과 같음): 움직이는 쪽의 **모든** 조각 부분이 선을 축으로 180° 넘어가 반대쪽에 평평하게 놓인다.
  - **위 N겹 접기** `Fold(grab, drop, mountain, n)`, n ≥ 1 — 실제로 맨 위 몇 장만 집어 접는 동작:
    1. **잡은 더미**: grab 점을 포함하는(경계 포함, 1e-6) 조각들을 위에서부터 센다. 그 수를 M이라 한다. n ≥ M이면 전체 겹 접기와 같다. grab을 포함하는 조각이 없으면 거부(InvalidFold "잡은 곳에 종이가 없어요").
    2. **씨앗**: 잡은 더미의 위 n개 조각의 움직이는 쪽 부분.
    3. **함께 움직이는 것** (더 늘지 않을 때까지 반복, 움직이는 쪽 부분만 대상):
       - (이어짐) 움직이는 부분과 **원래 종이에서 변을 HINGE_MIN(0.02) 이상 공유**하는 부분. 단, 그 공유 변이 이번 접는 선 위에 있으면 이어진 것으로 보지 않는다(접는 선에서 갈라지므로).
       - (얹힘) 움직이는 부분과 테이블 위에서 겹치고(겹친 넓이 > 1e-7) **그보다 위 겹**인 부분 — 위에 얹힌 종이는 함께 들린다.
    4. 움직이는 집합에 들지 않은 조각은 **자르지 않고 그대로** 남는다(접는 선 자국도 생기지 않는다).
    - 결과: 접힌 모서리(이음선)로 아래 겹과 이어진 부분은 따로 접을 수 없고 함께 접힌다(진짜 종이처럼). 잘린 가장자리끼리만 겹친 곳(예: 대각선으로 반 접은 삼각형의 직각 꼭짓점, 다이아몬드 기본형의 덮개)은 위 몇 겹만 접을 수 있다.
    - 움직이는 집합에 안 든, 같은 쪽의 **떨어진 덮개**(잡은 겹과 이어지지도, 그 위에 얹히지도 않은 것)는 그대로 남는다.
  - **겹 순서**: 골접기 = 넘어간 조각이 전체 맨 위(시험판). 산접기 + 전체 겹 = 전체 맨 아래(시험판). 산접기 + 위 N겹(일부만 움직임) = 넘어간 조각이 **움직인 겹 중 가장 낮은 겹 바로 아래**에 끼워진다(그 높이 이상이던 남는 조각은 그만큼 위로). 넘어간 조각끼리는 순서가 뒤집히고 앞뒤 면이 바뀐다.
  - **접었다 펴기** `Crease(grab, drop, layers)`: 위와 똑같이 움직이는 집합을 정한 뒤 종이 모양·겹은 **바꾸지 않고**, 움직였을 각 조각 부분의 접는 선 위 변을 **접은 자국**으로 남긴다. 자국은 원래 종이 좌표의 선분으로 저장되어, 이후 종이를 접으면 그 종이 부분과 함께 움직인다. 화면에는 가는 선으로 보이고 놓기 자석(R-021)의 기준이 된다.
  - `Flip`: 종이 전체를 좌우로 뒤집는다(윤곽 가로 범위의 가운데 세로선 기준, 겹 순서 반대). 자국도 함께 뒤집힌다(종이에 붙어 있으므로).
  - `Undo`: 마지막 `Fold`, `Crease`, `Flip` 하나를 취소(자국도 함께 사라짐). 횟수 제한 없음.
  - `Unfold`(처음으로): 종이를 처음(조각 1, 흰 면 위, 자국 0) 상태로 되돌리고 되돌리기 기록을 비운다. 비용 없음. (가정: 페이즈 1에서는 "다시 시작" 버튼이다. 실제 종이처럼 펴도 자국이 남는 동작은 `Crease`만 만든다.)
- 기대 동작: "현재 접은 횟수" = 현재 상태에 적용된 `Fold` 수. `Crease`·`Flip`은 세지 않는다. "자국 수" = 적용된 `Crease` 수(같은 동작이 여러 겹에 남긴 선분은 1번으로 센다).
- 예외 상황 — 공통 검사 순서 RunEnded → WrongMode(앉음 아님) → NoSheet. 그 뒤:
  - `Fold`/`Crease`: layers < 0 → 거부(InvalidFold). 끌기 거리 < MIN_DRAG, 움직이는 부분 없음, 남는 부분 없음(접는 선이 종이 밖), 위 N겹에서 잡은 곳에 종이 없음 → 거부(InvalidFold), 상태 불변. 이유 문구는 시험판 문구 + "잡은 곳에 종이가 없어요".
  - `Undo`, `Unfold`: **되돌리기 기록이 비어 있으면** 거부(NothingToUndo). 이것이 유일한 조건이다(리뷰 N-6). 되돌리기 기록 = 이 종이에 적용된 `Fold`·`Crease`·`Flip` 목록(종이를 꺼낼 때와 `Unfold` 뒤에 비어 있음). 그래서 `Flip`만 한 종이(조각 1·자국 0이지만 뒷면이 위)도 `Unfold`할 수 있다(→ 흰 면 위 처음 상태, 기록 비움). 그 뒤 `Unfold`·`Undo`는 거부.

### R-008 튜토리얼 가이드 (첫 종이만)
- 설명: 런의 첫 `TakeSheet`로 나온 종이가 튜토리얼 종이다. 이 종이가 테이블에 있는 동안, 가이드를 끄지 않았고 현재 **동작 수** a(적용된 `Fold` + `Crease` 수, `Flip` 제외) < 6이면 종이비행기 a+1단계 가이드(잡을 곳 노란 공, 놓을 곳 초록 원, 이상적인 접는 선 빨간 점선, 단계 제목, 그 단계가 접었다 펴기면 "Ctrl을 누른 채 놓기" 안내)를 보여 준다. 종이비행기 1단계가 접었다 펴기라서, 튜토리얼에서 접기·접었다 펴기·자국 자석을 모두 한 번씩 써 본다.
- 기대 동작: 동작을 확정할 때마다 시험판과 같은 단계 정확도(0~100점)를 보여 준다(피드백 전용, 등급·가격에 영향 없음). 가이드 단계의 종류(접기/접었다 펴기)와 다른 동작을 하면 점수 0. `Undo`/`Unfold`하면 가이드 단계도 현재 동작 수에 맞춰 돌아간다. 놓을 곳 목표 자석(0.08)은 가이드가 보이는 동안만 작동하고 R-021 자석보다 먼저 적용된다.
- 예외 상황:
  - `SkipGuide` → 이 종이의 가이드가 사라지고 다시 켤 수 없다. 종이는 여전히 무료. 가이드가 보이지 않을 때 `SkipGuide` → 거부(NoGuide).
  - 튜토리얼 종이를 `Finish`/`Discard`하면 튜토리얼이 끝난다. 이후 이 런에서 어떤 종이에도 가이드가 나오지 않는다(다시 시도해도).
  - 튜토리얼 종이로 종이비행기가 아닌 모양을 만들어도 일반 판정(R-012)을 따른다.
  - 첫 종이를 2일차 이후에 꺼내도 그것이 튜토리얼 종이다.
  - 위 N겹 접기는 튜토리얼에서 가르치지 않는다(종이비행기에 필요 없음). 처음 필요한 작품(튤립) 책 쪽과 책 1쪽 "접기 기호"에서 설명한다.

### R-009 완성 · 버리기
- 설명:
  - `Finish`: 현재 종이를 판정(R-011~R-013)한다. 작품이면 (작품, 등급, 일치도)를 오늘 진열 목록에 추가하고 그 작품의 등급별 완성 수 +1. 작품이 아니면 "구겨진 종이": 실패 수 +1, 진열 안 됨. 어느 쪽이든 종이는 테이블에서 사라진다.
  - `Discard`: 판정 없이 실패 수 +1, 종이가 사라진다.
- 기대 동작: 돈은 완성 시 바뀌지 않는다(저녁 정산에서 들어온다).
- 예외 상황 — RunEnded → WrongMode → NoSheet → (`Finish`만) NoFolds(현재 접은 횟수 0 — 접었다 펴기·뒤집기만 한 종이도 NoFolds).

### R-010 책 열람
- 설명: 책은 책장 읽기 모드 또는 앉음+책 펼침에서만 보인다. 책은 쪽의 나열이다: [0 목차][1 접기 기호] + 작품마다 카탈로그 순서로 [표지, 1단계, …, N단계, 완성]. 총 44쪽(0~43, 쪽 번호는 `CONTENT_SPECS.md` §3).
  - **펼침(두 쪽)**: 책은 항상 (짝수 쪽, 그다음 홀수 쪽)을 함께 보여 준다. **현재 쪽은 늘 펼침의 왼쪽(짝수) 쪽**이다.
  - `TurnPage(p)`: p를 [0, 43]으로 맞춘 뒤(작으면 0, 크면 43) 짝수로 내린다(p − p mod 2). 예: −1 → 0, 17 → 16(16·17 펼침), 43 → 42, 99 → 42.
  - Runtime: ←/→ = `TurnPage(현재 − 2)` / `TurnPage(현재 + 2)`. 목차에서 작품을 누르면 `TurnPage(그 작품 표지 쪽)` — 표지가 홀수 쪽이면 펼침 오른쪽에 보인다.
- 기대 동작: 보유한 작품은 모든 쪽을 볼 수 있다. 보유하지 않은 작품은 표지(실루엣·이름·난이도·동작 수·기본가·페이지 가격·구입 버튼)만 보이고 단계·완성 쪽은 "봉인됨"으로 보인다. 목차·접기 기호 쪽은 항상 보인다.
- 예외 상황: 0쪽에서 ← 는 `TurnPage(−2)` = 0(변화 없음), 42쪽에서 → 는 `TurnPage(44)` = 42. 책을 닫았다 다시 열면 마지막 현재 쪽이 열린다(런 안에서 유지, `NewRun` 시 0).

### R-011 윤곽 일치도
- 설명: 두 종이 상태 A(플레이어), B(작품 기준 = 그 작품의 기준 접기 순서를 처음 종이에 정확히 적용한 결과)의 일치도:
  1. 각 상태의 **윤곽** = 모든 조각을 위에서 본 다각형들의 합집합(겹 수·겹 순서·앞뒤 면·산/골·**접은 자국 무시**).
  2. 각 윤곽을 넓이 무게중심이 (0,0)이 되도록 평행이동.
  3. B 윤곽에 정사각형 대칭 8가지(0°/90°/180°/270° 회전, 그리고 각각 x → −x 좌우 반전)를 적용한 각각에 대해 IoU = 넓이(A ∩ gB) ÷ 넓이(A ∪ gB).
  4. 일치도 s = 8개 IoU의 최댓값(0~1). 일치도 % = floor(s × 100 + 1e-9)(부동소수 오차 보정).
- 기대 동작: 접는 순서, 어느 쪽 모서리부터 접었는지, 종이를 뒤집었는지, 종이의 테이블 위 위치는 결과에 영향이 없다. 기준 순서를 정확히 따르면 s = 1(계산 오차 MATCH_ERROR_MAX 이내).
- 예외 상황: 계산 방법(정확한 다각형 연산 또는 격자 샘플링)은 architect가 정하되 `CONTENT_SPECS.md` §4 기준값과 ±0.01 이내여야 한다.
- 겹·자국과 판정 (설계 결정): 판정은 **윤곽만** 본다. 접은 자국과 겹 순서는 점수에 직접 들어가지 않는다. 그래도 두 기법은 결과에 영향을 준다.
  - 위 N겹 접기는 **윤곽을 바꾼다**. 아래 겹은 제자리에 남고 위 겹만 밖으로 나가므로, 전체 겹 접기로는 같은 윤곽이 안 나온다. 책 순서의 위 N겹 단계를 전체 겹으로 바꾸면 튤립·매미 모두 구겨진 종이다(J-14, J-15). 튤립은 전체 겹 접기만으로 책 접기 수(5)까지 탐색해도 ★2에 못 닿는다(`CONTENT_SPECS.md` §4.2 [3]). 즉 **★2 이상에는 위 N겹 접기가 필요하다**(★1 근처까지는 다른 방법이 있을 수 있다 — 탐색은 증명이 아님).
  - 접었다 펴기는 윤곽을 바꾸지 않는다. 대신 정확한 기준점을 만들어(R-021) 등급을 올린다. 자국 없이 같은 위치를 손으로 맞추면 같은 점수다(J-16).

### R-012 작품 판정과 등급
- 설명: 후보(R-013) 각각의 일치도 중 최댓값인 작품을 고른다(같으면 카탈로그 순서가 앞선 작품). 그 일치도 %가
  - 97 이상 → ★3, 93~96 → ★2, 85~92 → ★1, 85 미만 → 구겨진 종이(작품 아님).
- 기대 동작: 결과 화면에 "작품 이름 ★n (일치도 xx%)" 또는 "구겨진 종이 (가장 비슷한 작품: 이름 xx%)"를 보여 준다.
- 예외 상황: 후보가 없을 수 없다(plane, house는 항상 보유).

### R-013 판정 후보
- 설명: 판정 후보 = 완성 시점에 보유한 책 페이지의 작품. 보유하지 않은 작품 모양은 후보가 아니다.
- 기대 동작: 페이지를 산 직후 완성한 종이부터 그 작품이 후보가 된다.
- 예외 상황: 보유하지 않은 작품을 정확히 접어도, 보유 작품 중 일치도가 85% 이상인 것이 없으면 구겨진 종이다.

### R-014 책 페이지 구입
- 설명: 책이 보이는 상태(책장 읽기 또는 앉음+책 펼침)에서 `BuyPage(m)` → 돈 −페이지 가격, 총 책값 +가격, m 보유.
- 기대 동작: 즉시 m의 단계 쪽을 볼 수 있고 판정 후보가 된다. 런 끝까지 유지.
- 예외 상황 — RunEnded → WrongMode(책이 보이지 않음) → UnknownModel(없는 ID, 빈 문자열, null) → AlreadyOwned → NotEnoughMoney(돈 = 가격이면 허용, 돈 0). 종이를 접는 중에도 살 수 있다(앉음+책 펼침).

### R-015 판매 가격
- 설명: 작품 1개 판매가 = `floor(기본가 × GRADE_PCT × 수요PCT / 10000)`, 수요PCT = 판매일의 인기 작품이면 150, 아니면 100.
- 기대 동작: 예) 강아지(18) ★3 인기 → floor(18×150×150/10000) = 40. 매미(26) ★2 일반 → 26.
- 예외 상황: 인기 작품의 페이지가 없어도 표는 바뀌지 않는다.

### R-016 하루 정산 (잠자기)
- 설명: `Sleep(yes)` → 오늘 진열 목록의 모든 작품을 R-015 가격으로 팔아 합계를 돈과 총 판매액에 더하고 목록을 비운다. 그다음
  - 일차가 7이면 런 종료(완주). 일차 7 유지.
  - 아니면 일차 +1, 오늘 남은 종이 5, 모드 걷기(캐릭터는 시작 위치 `CONTENT_SPECS.md` §6), 파산 검사(R-017).
- 기대 동작: 정산 내역(작품별 등급·가격, 합계, 정산 후 돈)을 정산 화면에 보여 준다.
- 예외 상황: 진열 0개 → 합계 0.

### R-017 파산
- 설명: 새 날이 시작될 때(R-016 일차 +1 직후) 돈 < PAPER_COST(2)이면 즉시 런 종료(파산). 일차는 새 날 값.
- 기대 동작: 낮 동안 돈이 0이 되어도 파산이 아니다. 돈 = 2면 파산 아님.
- 예외 상황: 7일차 정산 후에는 검사하지 않는다. 무료 튜토리얼 종이가 아직 남아 있어도 검사는 같다.

### R-018 엔딩 판정
- 설명: 런 종료 시 위에서부터 검사해 처음 만족하는 엔딩 하나.

| 우선순위 | ID | 이름 | 조건 |
|---|---|---|---|
| 1 | E-01 | 빈손 | 종료 사유 파산 **또는** 최종 돈 ≤ 20 |
| 2 | E-02 | 튤립 꽃밭 | 튤립 완성 수(등급 무관) ≥ 12 |
| 3 | E-03 | 종이접기 명인 | 5종 작품(plane, house, tulip, dog, cicada) 각각 ★3 완성 수 ≥ 1 |
| 4 | E-04 | 종이 재벌 | 최종 돈 ≥ 600 |
| 5 | E-05 | 동네 종이접기 공방 | 위 모두 불만족 |

- 기대 동작: 입력은 종료 사유, 최종 돈, 작품별·등급별 완성 수뿐(순수 함수). 한 번 정해지면 바뀌지 않는다.
- 예외 상황: `NewRun`으로 중단한 런은 판정하지 않는다. 구겨진 종이·버린 종이는 완성 수가 아니다.

### R-019 명령 거부 일반 규칙
- 설명: 규칙에 맞지 않는 명령은 예외로 멈추지 않고 거부되며 상태를 전혀 바꾸지 않는다. 사유: RunEnded, WrongMode, UnknownTarget, SheetOnTable, NoSheetsLeft, NotEnoughMoney, NoSheet, InvalidFold, NothingToUndo, NoFolds, NoGuide, UnknownModel, AlreadyOwned.
- 기대 동작: 모든 명령은 먼저 RunEnded(런 종료 후, `NewRun` 제외), 다음 WrongMode를 검사한다. 이후 순서는 각 규칙에 적힌 대로.
- 예외 상황: `Interact(t)`의 t가 네 대상이 아니면(null 포함) UnknownTarget(WrongMode 다음).

### R-020 기록
- 설명: 런 기록 = 최종 돈, 작품별·등급별 완성 수, 실패 수(구겨진 종이 + 버린 종이), 총 판매액, 총 종이값, 총 책값, 보유 페이지. 결과 화면에 표시.
- 기대 동작: 돈 = 20 + 총 판매액 − 총 종이값 − 총 책값이 항상 성립한다.
- 예외 상황: 없음.

### R-021 놓기 자석 (입력 보조 — 난이도 수치)
- 설명: 접기·접었다 펴기를 끌어 놓을 때 놓는 점 d를 아래 순서로 한 번만 고친다(먼저 맞는 것 하나). 미리보기·확정 모두 고친 점을 쓴다.
  - **기준점** = 현재 종이의 모든 조각 꼭짓점(잡은 점 자신 제외, 시험판 자석과 같음) + **보이는 자국 점**(접은 자국이 조각 경계에서 끝나는 점, 자국끼리 만나는 점. 그 점을 덮는 더 위 겹 조각이 있으면 보이지 않음).
  0. (튜토리얼 가이드가 보일 때) 목표 놓을 곳 0.08 안 → 목표점.
  1. **P 기준점**: d에서 SNAP_POINT(0.06) 안의 가장 가까운 기준점으로.
  2. **L 접는 선 맞춤**: 지금 접는 선(grab–d 수직이등분선)에서 SNAP_LINE(0.04) 안에 있는 기준점 중, 서로 LINE_PAIR_MIN(0.2) 이상 떨어진 두 점(선까지 거리 합이 가장 작은 쌍)을 지나도록 접는 선을 옮긴다. 놓는 점 = 그 선에 대한 grab의 대칭점. ("이 두 점을 잇는 선으로 접으세요"라는 도해를 그대로 따를 수 있다.)
  3. **M 자국 선**: d에서 SNAP_MARK(0.04) 안의 보이는 자국 선 위 가장 가까운 점으로("모서리를 자국 선에 맞추세요").
  4. 없으면 d 그대로(자유).
  - **동점 처리(결정적, 리뷰 N-8)**: 거리는 1e-9 단위로 반올림해 비교한다. P·M은 (거리, 고친 점의 x, y) 순으로 가장 작은 것. L은 각 쌍의 두 점을 (x, y) 순으로 정렬해 (앞 점, 뒤 점)으로 두고 (거리 합, 앞 점 x, 앞 점 y, 뒤 점 x, 뒤 점 y) 순으로 가장 작은 쌍. 기준점 목록의 순서는 결과에 영향을 주지 않는다(`balance_check.py` `snap`).
- 기대 동작: 정확한 기준 순서 입력은 자석을 거쳐도 바뀌지 않는다(`balance_check.py recog`의 "자석" 줄). 자석이 걸리면 놓는 점 표시가 초록색으로 바뀌고 걸린 기준점·선을 강조한다.
- 예외 상황: 자석은 Core 명령(`Fold`/`Crease`)의 좌표를 만드는 입력 단계다. Core 명령은 받은 좌표를 그대로 쓴다(테스트는 정확한 좌표로). 기준점 계산은 결정적이어야 하므로(같은 상태·같은 d → 같은 결과) architect가 Core 순수 함수로 두기를 권한다.

## 승리 / 패배
- 명확한 승패 없음. 런은 7일차 잠자기(완주) 또는 새 날 아침 돈 < 2(파산)로 끝나고 엔딩 1개 + 기록으로 평가한다. E-01이 사실상 패배, E-02~E-04가 목표형, E-05가 보통 엔딩.
