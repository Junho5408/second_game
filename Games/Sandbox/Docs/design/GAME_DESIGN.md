# Sandbox 게임 기획

> 담당: game-designer

## 콘셉트 (한 줄)
버튼을 빠르게 연타해 콤보 배수를 쌓고 점수를 올리는 초소형 "점수 카운터" 장난감.

## 핵심 재미
- 리듬을 끊지 않고 연타할수록 배수가 올라가 점수가 눈에 띄게 빨리 오르는 손맛.
- 1초 안에 다음 입력을 넣어야 한다는 가벼운 긴장감.

## 타깃 경험
- 설명 없이 10초 안에 규칙을 이해한다.
- 팀 파이프라인(기획 → 설계 → 구현 → 리뷰 → QA) 검증용 샘플이므로 규칙은 작고 완전히 테스트 가능해야 한다.

## 핵심 게임 루프
1. Space 키를 누르거나 마우스를 클릭한다(= 입력 1회).
2. 점수가 `기본 점수 × 현재 콤보 배수`만큼 오른다.
3. 1.0초 이내에 다시 입력하면 콤보가 이어지고, 늦으면 콤보가 끊긴다.
4. 원하면 리셋으로 점수와 콤보를 0으로 되돌린다.

세부 수치와 규칙은 `GAME_RULES.md`, 기능 명세는 `FEATURE_SPECS.md`(F-001)를 따른다.

## 진행/성장 구조
없음. 한 세션 안에서 콤보 배수(x1 → x4)만 단계적으로 오른다.

## 범위 (하지 않을 것 포함)
- 포함: 입력 1종(Space/클릭 동일 취급), 점수, 콤보, 콤보 배수, 리셋, 현재 점수·콤보·배수 표시.
- 제외: 최고 점수 저장, 저장/불러오기, 타이머·제한 시간, 승패, 사운드/이펙트 요구사항, 레벨·아이템, 온라인 기능.
